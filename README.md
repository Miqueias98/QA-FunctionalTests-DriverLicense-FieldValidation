🧩 Projeto: Testes Funcionais – 2ª Sprint QA (Classes de Equivalência e Casos de Teste)

🧠 Visão Geral

Este projeto apresenta a aplicação prática de testes funcionais manuais, utilizando a técnica de classes de equivalência para validar o comportamento do campo “Nome” em um formulário de sistema.
O objetivo foi garantir que o campo aceite apenas valores válidos conforme as regras de negócio definidas, assegurando a integridade e a usabilidade do sistema.

🎯 Objetivo

Validar o funcionamento correto do campo “Nome”, assegurando que:
	•	Valores válidos sejam aceitos corretamente.
	•	Valores inválidos sejam rejeitados de acordo com os critérios estabelecidos.
	•	As mensagens de erro e sucesso estejam alinhadas ao comportamento esperado.

🧪 Estrutura de Testes

Tipo de Teste 

Teste Funcional
Validação do comportamento do campo “Nome”.

Classes de Equivalência
Identificação de faixas válidas e inválidas para entrada de dados.

Testes Manuais
Execução prática dos cenários definidos em planilha.

📋 Casos de Teste

Foram definidos e executados 10 casos de teste, cobrindo entradas válidas e inválidas como:
	•	Campos vazios;
	•	Caracteres especiais;
	•	Limites de caracteres mínimos e máximos;
	•	Entradas alfabéticas válidas;
	•	Combinações de letras, números e símbolos.
